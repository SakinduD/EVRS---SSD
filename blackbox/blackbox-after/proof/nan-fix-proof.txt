ZAP-2 follow-up: unhandled NaN in POST /score
=============================================

The before-scan raised an unhandled ValueError on /score/events_debug ("NaN
values are not JSON compliant", HTTP 500). That endpoint was removed, but the
same defect survived in the response builder of POST /score, which is the
endpoint the Node backend actually calls. It was found when the admin
"Manage Risks" page failed with a network error against the real database.

Root cause
----------
_score_dataframe() guarded dose_number and index_v_date with pd.notna(), but
returned citizenId and index_v_code straight off the row. pandas only produces
NaN for a *mixed* column: if no citizen in the batch has a vaccine code the
column keeps dtype object and None survives, but if some do, the column is
typed and the missing ones become NaN. Starlette renders responses with
json.dumps(allow_nan=False), so one NaN turns the whole batch into a 500.

Every batch the backend sends is mixed. Every fixture in the test suite was
not, which is why the tests passed while the feature was broken.

  pandas 3.0.6 behaviour, column "index_v_code":
    all None         -> dtype object  -> None   (serialises)
    mixed None/str   -> dtype str     -> nan    (raises)
    all str          -> dtype str     -> 'BCG'  (serialises)

Fix
---
app.py: added _json_safe(), which maps a pandas missing value onto None, and
applied it to citizenId and index_v_code in _score_dataframe().

  NAN-PROBE-2  v1Code = null    }  column typed and the missing value NaN

  The admin Manage Risks page renders against the real database again.

Regression test
---------------
tools/contract_test.py gained citizen CTR-0003 (a dose with no vaccine code),
which makes its batch mixed, plus an explicit assertion that no result value
is NaN. Before the fix this payload returned 500 and the run failed at the
first check.

  pass  Node-shaped payload accepted  HTTP 200
  pass  response has a 'results' array
  pass  result[0] has all mapped fields
  pass  result[1] has all mapped fields

  pass  risk_prob is numeric
  pass  citizen with no vaccination history handled  scored: ['CTR-0001', 'CTR-0003']

  pass  same payload without the token is refused  HTTP 401
  
  Contract holds: the scorer answers what adminController.js expects.
